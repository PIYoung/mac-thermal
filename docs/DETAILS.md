# 측정 방식과 기술 설명

[한국어 README](../README.md) · [English](../README.en.md) · [日本語](../README.ja.md) · [简体中文](../README.zh-CN.md)

이 문서는 Mac Thermal v2.7.0 개발 버전의 표시 기준과 구현상 한계를 설명합니다. 소스 코드는 MIT 라이선스로 제공하며, 타사 고지는 [THIRD_PARTY_NOTICES.txt](../THIRD_PARTY_NOTICES.txt)를 따릅니다.

## 실행 환경

- 실행: Apple Silicon ARM64, macOS 14 이상. Intel 빌드는 제공하지 않습니다.
- 빌드: macOS 26 SDK를 포함한 Xcode 26 또는 호환 Command Line Tools. 실행 대상 버전과 빌드 SDK 버전은 다릅니다.
- macOS 26 이상에서는 AppKit의 `NSGlassEffectView`를 사용하고, 이전 macOS에서는 표준 반투명 패널로 표시합니다.
- CPU 온도 센서는 Apple M4 Pro에서 실제 읽기를 검증했습니다. 다른 칩의 센서 호환성과 macOS 14·15에서의 전체 동작은 별도로 검증하지 않았습니다.
- SMC 및 HID 센서 접근은 공개적으로 문서화되지 않은 시스템 인터페이스를 포함하므로 하드웨어·OS 업데이트에 따라 읽기가 제한되거나 바뀔 수 있습니다. 센서를 읽을 수 없으면 `—`를 표시하고 다른 값을 정상 측정값처럼 대신하지 않습니다.

## 수집과 저장

측정은 2초마다 백그라운드 큐에서 수행합니다. 그래프는 실제 표본만 메모리에 유지하며 시작 전 이력을 임의 데이터로 채우지 않습니다. 측정 기록을 디스크에 저장하거나 서버로 전송하지 않습니다. 언어, 마지막 선택 탭, 메뉴 막대 움직임 등의 사용자 설정은 로컬 `UserDefaults`에 저장합니다.

계정·외부 라이브러리·원격 통계 서버·관리자 helper를 사용하지 않습니다. Codex 집계도 승인한 로컬 기록만 읽으며 계정 서비스에 접속하지 않습니다. 팬 제어, 전력 제한 변경, 다른 앱 종료 기능도 없습니다. 센서 조회를 위해 App Sandbox는 사용하지 않으며 현재 사용자 권한에서 실행됩니다. 읽지 못하는 프로세스나 센서를 위해 권한을 확대하지 않습니다.

## 온도와 열 상태

| 항목 | 기준 |
| --- | --- |
| CPU 온도 | 읽기에 성공한 CPU 코어 센서의 최댓값. 평균 온도가 아닙니다. 우선 SMC 키를 읽고, 값이 없으면 인식 가능한 HID CPU 센서를 확인합니다. |
| SSD 온도 | 내장 SSD의 HID `NAND CH* temp` 센서 중 최댓값. 없으면 SMC `TH0x`를 확인합니다. |
| 메모리 온도 | 제공하지 않습니다. 확인되지 않은 PMU 값을 RAM 온도로 표시하지 않습니다. |
| 열 상태 | `ProcessInfo.processInfo.thermalState`의 `nominal` / `fair` / `serious` / `critical`을 사용합니다. 온도 숫자로 자체 판정하지 않습니다. |

CPU 센서의 현재 SMC 키 목록은 [ThermalSensors.c](../Sources/ThermalSensors.c)에 있습니다. PMU `tdie`·`tdev` 값은 CPU 온도에 포함하지 않습니다. 유효 범위를 벗어나거나 비정상인 온도는 제외합니다.

열 상태가 `fair`이면 메뉴 막대 글자와 온도 숫자를 주황색, `serious`·`critical`이면 빨간색으로 표시합니다. 정상으로 돌아오면 기본 색상으로 복구합니다. 경고는 상태를 알려주는 표시이며 냉각을 직접 제어하지 않습니다.

센서 프로토콜과 매핑을 참고한 공개 소스:

- [Stats v3.0.21 SMC 프로토콜](https://github.com/exelban/stats/blob/v3.0.21/SMC/smc.swift)
- [Stats v3.0.21 센서 매핑](https://github.com/exelban/stats/blob/v3.0.21/Modules/Sensors/values.swift)
- [Apple thermalState](https://developer.apple.com/documentation/foundation/processinfo/thermalstate-swift.enum)

## CPU 사용률과 그래프

시스템 전체 CPU 사용률은 연속 표본 사이의 CPU 누적 tick 차이로 계산한 0~100% 값입니다. 첫 구간은 기준값이므로 측정 중으로 표시합니다.

CPU 탭은 사용률과 최근 1분 그래프를 중심으로 구성하며, CPU 온도·열 상태와 CPU 사용량 TOP 3 프로세스를 함께 표시합니다. 그래프는 0~100% 고정 눈금의 선과 은은한 면으로 표시합니다. 미측정·잠자기 등으로 6초 넘게 비는 구간은 연결하지 않습니다. 최근 이력은 최대 120점으로 제한하고 표시 시간 범위를 벗어난 표본을 제거합니다.

## GPU 사용률과 그래프

GPU 탭은 IOKit `AGXAccelerator` 서비스의 `PerformanceStatistics`에 있는 `Device Utilization %`를 전체 사용률로 표시합니다. Renderer·Tiler 값을 더하거나 전력에서 사용률을 추정하지 않습니다. 드라이버가 보고하는 유한한 0~100% 숫자만 유효하며, 실제 유휴 값 0과 미지원·조회 실패를 구분합니다. 값이 없으면 메뉴바는 `—`, GPU 패널은 `정보 없음`을 표시합니다.

모델과 코어 수는 같은 서비스의 속성에서 별도로 읽습니다. Apple M4 Pro 20코어에서 현재 사용자 권한의 실제 읽기를 검증했으며, 다른 칩·macOS 버전에서 같은 필드 제공을 보장하지 않습니다. IOKit 접근에 사용하는 시스템 API와 별개로 이 드라이버 속성 계약은 문서화되지 않았습니다. GPU 온도·주파수·전력·NPU 사용률은 제공하지 않습니다.

레지스트리 서비스와 모델 정보를 재사용하며, 서비스가 사라지면 해제하고 다시 탐색합니다. 장치가 없을 때는 매 표본 전체를 탐색하지 않고 재시도 간격을 둡니다. 2초마다 숫자를 읽으며 별도 명령 실행·관리자 권한·helper를 사용하지 않습니다. GPU 그래프는 CPU와 같은 최근 1분·0~100% 눈금과 미측정 구간 처리 기준을 사용합니다.

## 메모리

메모리 탭은 전체·사용 중 메모리와 커널이 보고하는 메모리 압박을 중심으로, 압축 메모리의 물리 저장 크기·스왑 사용량과 메모리 사용량 TOP 3 프로세스를 함께 표시합니다.

사용량은 VM의 활성·비활성·고정·압축 페이지에서 purgeable·파일 캐시 페이지를 뺀 추정치입니다. Activity Monitor와 바이트 단위 일치를 보장하지 않습니다. 메모리 압박 색상은 사용률로 추정하지 않으며, 압박 정보를 읽을 수 없으면 정보 없음으로 표시합니다.

## TOP 3 프로세스

- 읽을 수 있는 프로세스 중 CPU 사용량과 physical footprint 각각 상위 3개를 CPU·메모리 탭 안에 표시합니다. 별도의 TOP 3 탭은 없습니다.
- 같은 앱에 속한 여러 프로세스를 합산하지 않습니다. 앱 단위 순위와 다를 수 있습니다.
- CPU는 두 실제 표본 사이 CPU 시간 차이를 전체 논리 코어 수로 나눈 0~100% 값입니다. Activity Monitor의 한 코어=100% 표기와 다릅니다.
- Mach timebase로 CPU 카운터를 환산하고, PID와 시작 시각을 함께 비교해 PID 재사용을 구분합니다.
- 첫 CPU 표본은 기준값입니다. 메모리 순위는 첫 표본부터 표시합니다.
- 종료·권한 제한 등으로 읽지 못한 프로세스 수를 함께 표시합니다.
- 프로세스 이름과 PID·사용량을 사용하며, 경로·실행 인자는 수집하지 않습니다.

## SSD 용량과 읽기·쓰기

SSD 탭은 사용 용량 비율·남은 공간과 읽기·쓰기 속도 그래프를 중심으로 표시하며, 온도는 보조 정보입니다. 용량은 시동 Data 볼륨의 전체·사용 가능 공간입니다. APFS 공유 공간의 `statfs.f_bavail`을 기준으로 하므로 Finder의 purgeable 포함 추정치와 다를 수 있습니다.

읽기·쓰기 속도는 내부 물리 SSD의 누적 바이트 차이를 실제 경과 시간으로 나눕니다. **Data 볼륨만의 활동이 아닌 내부 물리 SSD 전체** 기준입니다. 외부 장치, 디스크 이미지, APFS 하위 계층을 중복 합산하지 않습니다.

첫 표본·장치 변경·카운터 리셋 구간은 기준값으로 처리합니다. 실제 유휴 속도인 0은 그대로 표시합니다. 그래프는 최근 1분 실측값을 메모리에 유지합니다.

## 네트워크

네트워크 탭은 다운로드·업로드 속도와 각각의 최근 1분 그래프를 표시합니다. UP/RUNNING 상태인 `en숫자` Wi-Fi·유선 인터페이스별 64비트 누적 바이트 차이를 실제 경과 시간으로 나눕니다. VPN·loopback·브리지는 합산하지 않으므로 다른 네트워크 모니터의 전체 트래픽 값과 다를 수 있습니다. 인터페이스 변경·카운터 리셋 구간은 무효 처리하고 다음 구간부터 계산합니다. 그래프는 메모리에 유지하는 최근 1분 실측값입니다.

메모리·프로세스 용량은 1,024 단위, SSD 용량과 전송 속도는 1,000 단위입니다. 예를 들어 전송 속도 `1 KB/s`는 1,000바이트/초입니다.

## 메뉴 막대 움직임

CPU 리듬 막대·순환 점, 네트워크 입자와 SSD 물결은 이 프로젝트에서 작성한 Core Graphics 도형·수학식입니다. 외부 애니메이션 라이브러리나 아이콘 경로를 사용하지 않습니다. 숫자는 실측값이고, 움직임은 그 값을 시각화한 표현입니다.

| 표시 | 움직임의 기준 |
| --- | --- |
| CPU 리듬 막대 | CPU 사용률에 따라 막대 진폭·리듬이 달라집니다. |
| CPU 순환 점 | CPU 사용률에 따라 활성 점 수와 회전 속도가 달라집니다. |
| GPU 타일 | 4×3칸의 점등 수는 사용률 눈금이며 실제 코어 수가 아닙니다. 부하에 따라 빛의 흐름 속도가 달라지고, 0%·미측정에서는 정지합니다. |
| 네트워크 | 업로드·다운로드 각각의 실측 속도와 전송 방향을 반영합니다. 속도가 0이면 해당 흐름은 멈춥니다. |
| SSD | 채움 높이는 사용 용량 비율입니다. 표면 물결은 읽기+쓰기 속도에 따라 움직이며 I/O가 없으면 평평하게 멈춥니다. |

기본 메뉴바는 CPU·GPU·SSD·네트워크 4항목을 모두 표시합니다. 설정에서 각 항목을 개별 체크하며 선택은 재실행 후에도 유지합니다. 기존 CPU·GPU 선택값은 해당 항목과 SSD·네트워크 선택으로 이전합니다. 모든 항목을 끄면 작은 MT 버튼을 남겨 설정을 다시 열 수 있게 합니다. 항목 너비는 실제 두 줄의 글자 길이에 맞추고 항목 사이에는 작은 동일 간격을 둡니다. 숨긴 항목은 자리와 애니메이션 활동에서 제외하며, 열린 패널의 위치와 크기는 바꾸지 않습니다. CPU의 기본 움직임은 리듬 막대이며 움직임 켜짐·강도 1.2배입니다. 설정에서 강도를 0.75~1.5배로 바꿀 수 있습니다. 정적 글자는 표본·화면 모드가 바뀔 때만 다시 그리고 작은 도형을 최대 8fps로 합성합니다. 무한 CALayer 애니메이션은 사용하지 않습니다.

사용자 움직임 끄기, macOS 동작 줄이기, 잠자기, 화면 꺼짐, 모든 지표가 유휴 상태일 때는 애니메이션 타이머를 멈춥니다. 메뉴 막대는 표시한 지표 그룹만 실제 글자 길이에 맞춰 배치합니다. SSD와 네트워크 사이에도 불필요한 예약 여백을 두지 않습니다. 애니메이션 프레임·스타일 변경으로 폭이 바뀌지 않습니다. 항목 체크를 바꾸면 표시한 그룹의 폭만 즉시 적용합니다.

## Codex 메뉴바

Codex 데스크톱 앱 실행 중에만 자원 메뉴 항목 맨 왼쪽에 26pt 로봇 아이콘을 표시하며 설정에서 개별 해제할 수 있습니다. 메뉴바 숫자·문구는 없으며 오늘 토큰과 최근 기록 시각은 패널·툴팁에서 확인합니다. 처음 불러오는 기록에는 애니메이션을 재생하지 않습니다. 새로 확인한 최근 토큰 기록이 들어오면 자체 제작 로봇이 키보드를 두드리고, 추가 기록이 없으면 10초 뒤 멈춥니다. 기록 감지에는 수집 주기만큼 지연이 있으며 실시간 토큰 소비 여부는 확인할 수 없습니다. 작업 중·승인 대기·완료 상태나 토큰 생성 속도를 뜻하지 않습니다. 기존 8fps·동작 줄이기·움직임 끄기·잠자기 제한을 적용합니다.

## Codex 보조 패널

Codex가 실행 중이면 300×420pt의 별도 표면을 자원 패널 왼쪽에 함께 표시합니다. 두 표면은 하나의 표시 창 안에서 12pt 간격으로 배치해 그림자 여백이 옆 패널 클릭을 가로채지 않게 합니다. 화면 끝에서는 두 패널을 함께 화면 안으로 맞추며, 좁은 화면에서는 세로 스크롤로 두 표면을 유지합니다. 열릴 때만 전체 위치를 계산합니다.

Codex 앱 실행 경과 시간은 macOS의 실행 시각으로 계산합니다. 작업 활동 시간과는 별개입니다. 기록 읽기는 기본값이 꺼짐이며 사용자가 보조 패널의 스위치를 켠 뒤에만 `~/.codex/sessions`에서 모델명·토큰 숫자·시각을 추출합니다. 이 파일에는 대화 본문도 포함되어 있으므로 읽기를 켜면 해당 기록 파일에 접근한다는 점을 확인해야 합니다. 본문·명령·인증정보·지시문은 보관·표시·전송하지 않고 원본 파일도 수정하지 않습니다. API 키·모델 생성 호출·계정 서비스 접속·CLI 도우미·새 서버·Codex 설정 변경은 없습니다.

오늘 토큰과 모델별 집계는 UTC 날짜를 기준으로 이 Mac에서 읽을 수 있는 기록만 포함합니다. 계정 전체·다른 기기·API 청구·남은 사용 한도·실제 작업 활동 시간을 뜻하지 않습니다. 누적값의 검증된 증가량을 사용하고 중복·역행·잘못된 값을 더하지 않습니다. 읽기·메모리 한도를 두며 불완전한 결과는 표시합니다. 집계와 읽기 위치는 메모리에만 유지하고 읽기를 끄면 중지·초기화합니다. Codex 기록 형식이 바뀌거나 읽을 수 없으면 정보 없음으로 표시합니다.

## 패널·접근성·언어

탭은 CPU·GPU·메모리·SSD·네트워크 순서입니다. 최초 실행에서는 CPU를 선택하고, 이후 마지막 선택 탭을 로컬에 저장해 다시 엽니다. 별도의 요약 탭 없이 메뉴 막대에서 전체 지표를 보고 패널에서 자원별 상세 정보를 확인합니다.

자원 패널 본문은 340×420pt이며 그림자를 위한 투명 여백을 둡니다. 메뉴 막대와 보이는 본문 사이 간격은 2pt입니다. 클릭한 순간 화면 안으로 위치를 맞춘 뒤 열린 동안 좌표를 바꾸지 않습니다. 메뉴 막대 글자 길이 변화로 열린 패널이 움직이지 않습니다. 다른 앱으로 전환하거나 투명 여백 클릭·Escape·메뉴바 재클릭으로 닫을 수 있습니다. 설정의 팝업 메뉴가 키 포커스를 가져가는 것만으로 패널을 닫지 않습니다. 열기 요청은 활성화 알림이 누락돼도 제한된 재시도로 끝내며, 취소한 요청의 이전 콜백은 다시 열지 않습니다.

열릴 때 위쪽 중앙을 중심으로 0.45초 스프링 효과와 짧은 페이드인을 적용합니다. 동작 줄이기가 켜져 있으면 크기 변화 없이 페이드인만 사용합니다. 탭의 선택 배경은 0.18초 동안 이동하며, 늘어남·반동·내용 페이드는 사용하지 않습니다. 동작 줄이기에서는 즉시 전환합니다. 탭 버튼은 선택 상태를 접근성 API에 알리고 좌우 방향키·Home·End 이동을 지원합니다.

부팅 후 경과 시간은 `mach_continuous_time`을 사용해 잠자기 시간을 포함하고 시각 변경의 영향을 받지 않습니다. 앱 실행 후 경과한 시간이 아니며, 일·시간·분 단위로 표시합니다.

기본 언어는 macOS 언어와 관계없이 한국어입니다. 설정에서 English·日本語·简体中文으로 바꾸면 탭, 설정, 열 상태, 부팅 시간, 앱 툴팁과 접근성 설명이 즉시 바뀝니다. 실행 중인 프로세스 이름, 국제 단위와 CPU·GPU·SSD 이름, macOS 자체 UI의 언어는 변경하지 않습니다.

측정 주기는 2초로 유지합니다. CPU·메모리 순위에 필요한 수치는 전체 프로세스에서 읽고, 이름은 순위가 확정된 CPU·메모리 TOP 3의 서로 다른 PID에 대해서만 최대 6회 조회합니다. 메뉴 막대의 글자와 표시 너비는 값이나 모양이 바뀔 때 계산하고 애니메이션 프레임에서 재사용합니다.

패널이 닫혀 있어도 최신 측정값과 그래프 이력은 계속 기록합니다. 글자·접근성 값·그래프 표시 갱신은 패널이 열려 있을 때 선택한 탭에 수행하며, 패널을 다시 열거나 탭·언어를 바꾸면 저장된 최신값을 즉시 표시합니다.

## 빌드와 검증

기본 빌드·검사는 저장소 루트에서 실행합니다.

```sh
zsh build.sh
zsh scripts/check.sh
```

`check.sh`는 앱 빌드와 격리된 로컬 검증을 실행합니다. 번역·형식·언어 저장, 부팅 시간 경계값, CPU·GPU 이력, GPU 속성의 형식·범위 검증, 메뉴 막대 렌더링, 합성 프로세스 순위와 패널의 숨김·표시 갱신을 확인하며 사용자의 실제 언어·메뉴 막대 설정을 바꾸지 않습니다. 이 검증은 실제 재부팅·잠자기나 모든 Mac 모델에서의 호환성을 대신하지 않습니다.

메뉴 막대의 연속 프레임과 닫힌 패널의 측정값 적용 비용은 합성 데이터로 별도 측정할 수 있습니다.

```sh
zsh scripts/run_menu_render_probe.sh --benchmark
zsh scripts/run_panel_updates_probe.sh --benchmark
```

출력은 해당 코드 구간의 처리 시간이며 전체 앱 CPU 사용률이나 배터리 절감률이 아닙니다. 실행 환경의 영향을 받으므로 기본 검증에는 시간 임계값을 적용하지 않습니다. 센서 fallback 검증은 합성 SMC·HID 입력으로 CPU 센서 우선순위, SSD 값과 센서 수를 확인합니다.

리소스 측정의 실제 표본과 CPU 시간 단위는 추가 프로브로 확인할 수 있습니다.

```sh
mkdir -p build
xcrun clang -std=c11 -O2 -Wall -Wextra -Werror -I Sources tests/probes/resource_metrics_probe.c Sources/ResourceMetrics.c Sources/DiskMetrics.c -framework IOKit -framework CoreFoundation -o build/resource-metrics-probe
build/resource-metrics-probe
xcrun clang -std=c11 -O2 -Wall -Wextra -Werror -I Sources tests/probes/resource_cpu_units_probe.c Sources/ResourceMetrics.c -o build/resource-cpu-units-probe
build/resource-cpu-units-probe
```

첫 프로브는 실제 5회 측정의 초기 기준값·정렬·범위·리셋을 확인합니다. 두 번째는 짧은 자체 CPU 작업으로 Mach CPU 시간 변환을 `clock()`과 대조합니다. 다른 앱을 조작하거나 프로세스 이름을 출력하지 않습니다. 제한된 실행 환경에서 sysctl이 차단되면 해당 정보는 미확인으로 남습니다.

배포 앱은 ad-hoc 서명이며 Apple Developer ID 서명·공증을 받지 않았습니다. [README 설치 안내](../README.md#설치)의 제약을 확인하세요. 앱 번들에는 프로젝트 MIT 라이선스와 타사 고지·자산 출처를 포함합니다.
