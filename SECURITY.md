# Security

Mac Thermal reads local system metrics and provides an optional, explicitly confirmed disk cleanup workflow. It does not upload telemetry, require an account for local metrics, install a privileged helper, or control fans. It runs with the current user’s permissions and does not use App Sandbox.

The optional Codex companion reads the launch date supplied by macOS. Local usage aggregation is disabled by default and starts only after the user enables record reading. It reads only the current user's `~/.codex/sessions` tree to extract validated model identifiers, numeric token counters and timestamps. These record files also contain conversation text, so enabling this option grants the app access to files containing sensitive conversations. The parser does not retain, display, log or transmit message bodies, tool arguments, instructions, titles or working directories. Only bounded model/counter/date aggregates, opaque deduplication identifiers and parsing cursors remain in memory; source records are never changed. Turning record reading off stops reads and clears the in-memory aggregation. Local record aggregation does not read authentication/configuration files, follow symlinks outside the approved tree, copy credentials, contact an account service, invoke a CLI helper, start a server, change Codex settings or request a model call. Local UTC-day counts cover only records available on this Mac, not the entire account, API billing, remaining quota or verified active-work duration. Missing, inaccessible or incomplete data is labeled accordingly.

Account quota is a separate, default-off opt-in. The account review explains that the official Codex-managed ChatGPT credential is broader than statistics-only access. After consent, an independently installed, OpenAI-signed Codex executable runs as the current user with a private stdio connection and an isolated `CODEX_HOME` at `~/Library/Application Support/Mac Thermal/Codex Account` (directory mode 0700). No Codex binary or credentials are bundled. Existing desktop/CLI authentication and configuration are not imported. Codex manages its own file credential store; Mac Thermal never parses or accepts copied login tokens/API keys. The helper contacts OpenAI for authentication, refresh and account quota. Device-code sign-in uses only `https://auth.openai.com/codex/device`; the app does not enable device-code access or change account security settings if the account disallows it.

The client sends only initialization and the documented account read/login/cancel/logout/quota RPCs, rejects unsolicited requests, and never creates a thread, requests model generation or executes a tool/command. This RPC restriction is not a provider-enforced read-only credential scope. Only validated numeric quota windows and connection states enter monitor/rendering snapshots; account IDs, email, device codes, URLs and raw errors do not. Quota normally polls once a minute, stops on system sleep, and resumes an approved saved connection after wake/relaunch. Stale, missing and expired data is unknown; reset timestamps do not prove restored access. Disconnect requests logout, closes this app’s helper, then unlinks only its isolated `auth.json`, reporting a removal failure if needed. It does not revoke unrelated Codex sessions. Users can revoke provider access from their account. See [account integration](docs/CODEX_ACCOUNT.md) for version and compatibility limits.

Disk cleanup starts on explicit cleanup entry after the user has selected a local folder. The approved folder can be remembered and scanned on later cleanup entry; it is never scanned merely because the app launches, a tab changes or the panel reopens. It scans bounded file metadata without reading contents, suggests only old installers by prechecking them after a complete scan (large files and incomplete scans remain unchecked), and moves only explicitly selected regular files to Trash after a separate review. It does not permanently delete files, empty Trash, follow symbolic links, clean all caches, or request Full Disk Access. System and known cloud locations, package contents, and version-controlled project trees are excluded. Arbitrary third-party sync folders cannot all be detected; the UI asks the user to select a non-synced local folder. File and ancestor identities are checked again before each move; changed or inaccessible items are skipped. Results distinguish moved, skipped, and failed files, and moving to Trash is never reported as reclaimed space. Only the approved folder bookmark, exact physical path and stable ancestor identities are stored locally; the user can forget this record from the folder menu. Moved, replaced, newly protected or unverifiable locations require explicit selection again. Candidate paths, checkbox states, confirmations and results remain in memory and are not written to logs or uploaded.

Please do not post access tokens, private process names, personal paths, or detailed vulnerability exploits in public issues. If GitHub’s **Security → Report a vulnerability** option is available, use it. Otherwise, open an issue asking for a private contact without including sensitive details.

Only current source and release assets from this repository are supported. Check release filenames, the recorded commit and SHA-256 checksums before using a download. Checksums detect file differences; they do not replace Developer ID signing or Apple notarization. The initial release is ad-hoc signed and is not notarized.
